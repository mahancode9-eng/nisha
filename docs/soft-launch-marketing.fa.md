# بازاریابی Soft Launch نیشا — اینستاگرام + PV فروشنده

مکمل [`soft-launch-runbook.fa.md`](./soft-launch-runbook.fa.md). هدف: ۵–۱۰ فروشنده واقعی در دو هفته اول، بدون تبلیغ پولی تا وقتی ۵ سفارش مهمان واقعی ثبت شده باشد.

**نسخه HTML محلی (کپی یک‌کلیکی PV):** فایل [`soft-launch-marketing.html`](./soft-launch-marketing.html) را در مرورگر باز کن — سرور لازم نیست.

## مخاطب و وعده

**مخاطب پیش‌فرض:** فروشگاه‌های اینستاگرامی که الان با استوری/دایرکت می‌فروشند و لینک ویترین درست ندارند. صنایع‌دستی/خانگی اگر زود جواب دادند، اولویت با آن‌هاست.

**وعده اصلی (رقیق نکن):** شروع رایگان · کارت‌به‌کارت · بدون کارمزد روی هر سفارش · ویترین لینک‌دار.

**ادعای ممنوع در soft launch:** درگاه بانکی رسمی، اپ موبایل، «هزاران فروشگاه».

**CTA:** همیشه به ثبت‌نام ختم کن. دامنه زنده → لینک کامل؛ هنوز زنده نیست → «لینک در بایو» و در دایرکت شخصی بمان (ادعای «الان لایو است» نکن).

**یک خط موقعیت‌یابی:** نیشا = فروشگاه‌ساز برای فروشنده‌های اینستا که به‌جای «دایرکت بده» لینک ویترین + سفارش کارت‌به‌کارت می‌خواهند، بدون کارمزد روی فروش.

## کانال‌ها (هفته ۱–۲)

| کانال | نقش |
|---|---|
| فید + استوری اینستاگرام | آگاهی و اعتماد؛ ۱–۲ پست فید در هفته، استوری تقریباً روزانه |
| PV فروشنده (دایرکت / تلگرام) | تبدیل اصلی برای ۵–۱۰ فروشنده اول |

تا وقتی ۵ فروشنده حداقل یک سفارش مهمان واقعی داشته‌اند، تبلیغ پولی نزن.

## تقویم ۱۴ روزه اینستاگرام

ریتم: **یک پست فید یک‌درمیان** + **استوری بیشتر روزها**. کپشن کوتاه و فارسی.

| روز | نوع | موضوع | زاویه کپشن |
|---|---|---|---|
| ۱ | فید | مشکل | «هنوز فقط تو استوری می‌فروشی و دایرکت شلوغه؟» |
| ۱ | استوری | نظرسنجی | «سفارش‌هات کجاست؟ دایرکت / لینک فروشگاه» |
| ۲ | استوری | CTA نرم | ۳ اسلاید: مشکل → کارت‌به‌کارت → لینک بایو |
| ۳ | فید | مزیت | «روی هر سفارش کارمزد نده — فقط اشتراک پلتفرم اگر خواستی ارتقا بدی» |
| ۴ | استوری | پشت صحنه | اسکرین ویترین خالی / داشبورد (بدون دیتای واقعی دیگران) |
| ۵ | فید | نحوه کار | ۳ قدم: بساز → محصول بگذار → لینک بفرست |
| ۶ | استوری | پرسش | «پرداخت چطوریه؟» → کارت‌به‌کارت + آپلود رسید |
| ۷ | فید | اثبات سبک | نقل‌قول از ۱ فروشنده بتا یا داستان بنیان‌گذار |
| ۸ | استوری | اعتراض | «درگاه ندارم» → برای مشتری ایرانی کارت‌به‌کارت آشناست |
| ۹ | فید | قبل/بعد | قبل: لیست محصول تو هایلایت / بعد: ویترین مرتب با لینک |
| ۱۰ | استوری | دعوت نرم | «۵ فروشنده اول برای تست واقعی — دایرکت بده» |
| ۱۱ | فید | قیمت صادقانه | رایگان شروع؛ پلن‌ها برای امکانات بیشتر — نه کارمزد فروش |
| ۱۲ | استوری | دمو | ۱۵ثانیه: افزودن محصول → لینک ویترین |
| ۱۳ | فید | فوریت نرم | «این هفته دارم با فروشنده‌های واقعی راه می‌ندازم — جا هست؟» |
| ۱۴ | استوری + فید | جمع‌بندی | چه ساختیم + CTA ثبت‌نام / دایرکت |

**هشتگ (حداکثر ۵ تا در هر پست):** `#فروشگاه_اینستاگرام` `#کارت_به_کارت` `#فروشنده` `#نیشا`

**قواعد بصری:** اسکرین واقعی UI فارسی محصول/فروشگاه؛ بدون استوک بنفش/درخشان AI؛ استوری = ضبط صفحه گوشی معمولی.

## پیام‌های PV فروشنده (کپی/پیست)

`[YOUR-DOMAIN]` را با دامنه واقعی عوض کن. `[اسم]` را شخصی کن.

### ۱) اولین تماس سرد (دایرکت اینستا / تلگرام)

```
سلام [اسم]، ویترینت تو استوری قشنگه.
دارم نیشا رو برای فروشنده‌های اینستا راه می‌ندازم:
فروشگاه لینک‌دار + سفارش کارت‌به‌کارت، شروع رایگان، روی هر سفارش کارمزد نمی‌گیریم.
اگه دوست داری لینک بفرستم امتحان کنی؟
```

### ۲) اگر گفت بله — پک آنبوردینگ

```
عالی 🌱
۱) ثبت‌نام فروشنده: [YOUR-DOMAIN]/seller/register
۲) ویترینت را بساز و یک محصول واقعی بگذار
۳) لینک را تو بایو/استوری بگذار و یک سفارش تست بگیر

اگر جایی گیر کردی همین‌جا بگو — خودم راهنمایی می‌کنم.
پیام کوتاه دعوت:
«فروشگاه آنلاینت را رایگان بساز، با کارت‌به‌کارت بفروش، روی هر سفارش کارمزد نده.»
```

### ۳) فالوآپ اگر جواب نداد (۴۸ ساعت بعد)

```
[اسم] فقط خواستم یادآوری کنم — این هفته چند فروشنده اول را دستی راه می‌ندازم.
اگر الان وقت نداری اوکی؛ اگر خواستی لینک همان [YOUR-DOMAIN] هست.
```

### ۴) بعد از ساخت فروشگاه — فعال‌سازی

```
ویترینت بالاست 👏
قدم بعدی: لینک را تو استوری بگذار و از یک دوست بخواه یک سفارش تست (حتی ۱ تومن/محصول تست) بزنه.
اگر رسید/وضعیت سفارش گیج‌کننده بود اسکرین بفرست درستش می‌کنیم.
```

### ۵) درخواست معرفی (۳–۵ روز بعد از اولین سفارش)

```
ممنون که تست کردی.
یکی از دوستات که تو اینستا می‌فروشه و هنوز لینک فروشگاه درست نداره رو معرفی کن؟
برای ۵–۱۰ نفر اول پشتیبانی مستقیم خودمم.
```

### ۶) بستن بدون فشار

```
کاملاً اوکی اگر الان نه.
اگر بعداً از شلوغی دایرکت خسته شدی، نیشا همان لینک ویترین + کارت‌به‌کارت است — شروعش رایگانه.
```

**پیام کوتاه Day-0 (از ران‌بوک):**

> فروشگاه آنلاینت را رایگان بساز، با کارت‌به‌کارت بفروش، روی هر سفارش کارمزد نده.
> لینک: `https://YOUR-DOMAIN`

## ریتم outreach (چک‌لیست اپراتور)

1. لیست **۲۰** اکانت هدف بساز (فروشنده استوری/دایرکت).
2. حداکثر **۵ دایرکت در روز** بفرست (ریسک بلاک اسپم).
3. هدف: **۵–۱۰ آنبورد** با حداقل **۱ سفارش مهمان** برای هر کدام.
4. در شیت ساده لاگ کن (ستون‌ها پایین).

جریان:

```
لیست ۲۰ فروشنده IG
  → Day0 تماس سرد
  → جواب داد؟ → پک آنبوردینگ
  → جواب نداد؟ → Day2 فالوآپ
       → جواب داد؟ → پک آنبوردینگ
       → نه؟ → متوقف / بعداً گرم کن
  → کمک برای اولین سفارش مهمان
  → درخواست ۱ معرفی
```

## بعد از دو هفته

- اگر ۵ سفارش مهمان واقعی داری → می‌توانی تبلیغ سبک تست کنی.
- اگر کمتر از ۳ آنبورد → اول outreach دستی را بیشتر کن، تقویم محتوا را عوض نکن.
- باگهای واقعی فروشنده را اولویت بده؛ فیچر جدید را بلاک فروش نکن.
