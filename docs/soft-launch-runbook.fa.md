# راهنمای Soft Launch نیشا

مراحل عملی قبل از soft launch با ۵–۱۰ فروشنده واقعی. این سند مکمل [`qa-launch-checklist.fa.md`](./qa-launch-checklist.fa.md) است و روی اشتراک پلتفرم، کارت پرداخت و smoke test تمرکز دارد.

## ۱) مایگریشن دیتابیس

روی محیط staging/production:

```bash
cd backend
alembic upgrade head
```

مطمئن شو مایگریشن پلن‌های اشتراک (`subscription_plans` و جداول مرتبط) اعمال شده است.

## ۲) تنظیم کارت اشتراک در ادمین

1. وارد پنل ادمین شو: `/admin/settings`
2. بخش **کارت اشتراک پلتفرم** را پر کن: شماره کارت، نام صاحب کارت، بانک
3. اگر شماره کارت خالی باشد، صفحه تنظیمات ادمین هشدار می‌دهد و فروشنده بعد از checkout پیام «کارت پلتفرم هنوز تنظیم نشده» می‌بیند — soft launch اشتراک بلاک است تا این فیلد پر شود
4. ذخیره کن و یک بار صفحه را رفرش کن تا مقادیر تایید شوند

## ۳) Smoke test اشتراک (فروشنده رایگان → ارتقا)

با یک حساب فروشنده روی پلن رایگان:

1. `/seller/discounts` → باید گیت ارتقا دیده شود (ساخت کد تخفیف قفل)
2. `/seller/subscription` → پلن **حرفه‌ای** را انتخاب کن → چک‌اوت کارت‌به‌کارت
3. شماره کارت پلتفرم نمایش داده شود؛ مبلغ را (در تست می‌توانی واریز تستی/شبیه‌سازی کنی) و **رسید** را آپلود کن
4. وضعیت فروشنده: **در انتظار تایید مدیر**
5. ادمین: `/admin/subscriptions` → فاکتور را **تایید** کن
6. فروشنده را رفرش کن: پلن فعال عوض شده باشد و صفحه تخفیف/آمار/تنظیمات مطابق entitlement باز شود

## ۴) Smoke test خرید مهمان (پلن پایه+)

1. فروشگاهی که پلن **پایه یا بالاتر** دارد و در تنظیمات فروشگاه «خرید مهمان» را روشن کرده باشد
2. از ویترین عمومی بدون لاگین مشتری، یک سفارش کامل ثبت کن (سبد → چک‌اوت → آپلود رسید)
3. فروشنده سفارش را در پنل ببیند و وضعیت را جلو ببرد
4. روی فروشگاه پلن **رایگان** انتظار داشته باش که خرید مهمان فعال نشود / گیت entitlement اعمال شود

## ۵) کانال‌های عملیاتی (چک‌لیست env — بدون قرار دادن secret در git)

قبل از soft launch واقعی، در env پروداکشن/استیجینگ این‌ها را فعال/پیکربندی کن (مقادیر را فقط در secret store نگه دار):

- [ ] `SENTRY_DSN` (فرانت و بک‌اند در صورت جدا بودن)
- [ ] SMTP واقعی برای ایمیل تایید/بازیابی
- [ ] کانال SMS (اگر در این فاز استفاده می‌شود)
- [ ] URL عمومی API و CORS مطابق دامنه نهایی
- [ ] ذخیره‌سازی فایل/مدیا (S3 یا معادل) قابل دسترس از پروداکشن

## ۶) بکاپ و بازیابی

1. قبل از soft launch: بکاپ کامل دیتابیس + فایل‌های آپلود
2. یک بار **restore** روی محیط جداگانه تست کن تا بکاپ سالم باشد
3. محل نگهداری بکاپ و مسئول بازیابی را مشخص کن

## ۷) معیار Soft Launch (از چک‌لیست QA)

مطابق بخش soft launch در [`qa-launch-checklist.fa.md`](./qa-launch-checklist.fa.md):

- حداقل **۵ فروشنده** واقعی فروشگاه ساخته و حداقل یک سفارش کامل پردازش کرده‌اند
- **یک هفته** پایداری: بدون باگ بلاکر / خطای ۵۰۰ تکرارشونده
- کانال بازخورد فروشنده‌ها فعال باشد
- کارت اشتراک و smokeهای بخش ۳ و ۴ سبز باشند

وقتی این موارد سبز شد، می‌توانی به لانچ عمومی (بخش ۴ چک‌لیست QA) بروید.
